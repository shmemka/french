# Révisions Édito A1 — заметки для правок

- Исходники в `src/`. После любой правки: `python3 src/build.py` — пересобирает `index.html` и копирует `supabase.js`, `schema.sql`, `README.md`, `.nojekyll` в корень.
- `config.js` в корне содержит URL и publishable key Supabase; сборка его не перезаписывает.
- GitHub Pages публикует ветку `main`, папку `/` (корень).
- Порядок и количество заданий в RU (`data-*.js`) и EN (`en-*.js`) должны совпадать: ответы хранятся по индексу. Новые упражнения — только в конец темы.
- Облако: таблица `user_docs` (см. `schema.sql`), ключи документов `progress`, `settings`, `quiz`, `ans-<topicId>`.

## Два курса
- Переключатель FR / ES вверху сайдбара; выбранный курс — `localStorage["edito-course"]` и поле `course` в облачном документе `settings`. Атрибут `<html data-course="es">` включает тёплую тему.
- Испанский (Aula internacional Plus 1, юниты 1–3, вариант Испании — vosotros): `src/es-book.js` (хелперы + юнит 1), `es-book-2.js`, `es-book-3.js`, `es-gram.js` (спряжение -ar/-er/-ir, неправильные, произношение), `es-lexico.js` (лексика: [es, en, пример]), `es-test.js` (банк вопросов), `es-cheat.js` (шпаргалка `ES_CHEAT(LANG)`, раздел `#shpargalka` есть в обоих курсах).
- Испанский контент двуязычный: строки через `T(ru, en)`, собирается `ES_BUILD(LANG)` / `ES_POOL_BUILD(LANG)`. В объяснениях не сравнивать испанский с русским (исключение — возвратные глаголы); сравнения с английским — через `EsEN()`.
- id испанских тем начинаются с `es` — роутер по ним сам переключает курс. Прогресс и ответы хранятся по id темы, результаты пробных — с полем `c: "es" | "fr"`.
- Порядок и количество упражнений в теме менять только добавлением в конец (ответы хранятся по индексу).

## Платформа (вход, профиль, оформление)
- Модули `src/game.js` (виджет профиля в сайдбаре + журнал активности по дням), `src/platform.js` (экран входа/онбординг, аватар, оформление, личный кабинет), `src/study.js` (банк заданий `#bank`, карточный режим темы, «?» в пробной) встраиваются ВНУТРЬ IIFE движка: `build.py` подставляет их вместо маркера `/*@@MODULES@@*/` в `engine2.js`.
- Доступ только после входа (Supabase): `gateCheck()` → loading / auth / onboard. Без бэкенда — только онбординг локально.
- Облачные документы добавились: `profile` (имя, эмодзи, фон, выбранное оформление `eq`, тема light/dark/system) и `game` — сейчас из него используется только `hist` (сколько ответов в какой день) для календаря активности; старые поля xp/coins/streak/aw сохраняются, но не показываются.
- Геймификация (XP, уровни, монеты, стрик, магазин, промокоды) убрана по просьбе Влада 23.10.2026 — не возвращать без запроса. Всё оформление (палитры, рамки, узоры, курсоры, аватарки) доступно бесплатно во вкладке «Оформление».
- «Почему так» для каждого упражнения — `src/why.js` (`WHY[topicId][exIndex] = [ru, en]`); при добавлении упражнения в конец темы добавь и строку в WHY.
- Проверка текстовых ответов — только по Enter.
- Карточный режим (`study.js`): теория режется по h2/h3, затем карточка «Теперь — практика» и по карточке на каждое задание. Блоки `.exb` физически переносятся из `.exs` в колоду (на их месте комментарий-плейсхолдер) и возвращаются при закрытии — состояние заданий одно и то же в обоих режимах.
