# «Учим языки шаг за шагом» (бывш. Révisions Édito A1) — заметки для правок

- Исходники в `src/`. После любой правки: `python3 src/build.py` — пересобирает `index.html` и копирует `supabase.js`, `schema.sql`, `README.md`, `.nojekyll` в корень.
- `config.js` в корне содержит URL и publishable key Supabase; сборка его не перезаписывает.
- GitHub Pages публикует ветку `main`, папку `/` (корень).
- Порядок и количество заданий в RU (`data-*.js`) и EN (`en-*.js`) должны совпадать: ответы хранятся по индексу. Новые упражнения — только в конец темы.
- Облако: таблица `user_docs` (см. `src/static/schema.sql`), ключи документов `progress`, `settings`, `quiz`, `usets`, `profile`, `game`, `ans-<topicId>`. Библиотека Quizlet — отдельная таблица `qsets` в том же файле.
- Синхронизация: запись в облако через 0,7 с после изменения (`touch` → `flush`). Чтение — при загрузке (`initCloudRun`) и при возвращении на вкладку (`pullCloud`: visibilitychange / focus / online, не чаще раза в 4 с). Слияние в `mergeDocs(docs, pull)`; при pull документ `settings` (язык, курс) не применяется, а страница перерисовывается, только если это безопасно (`pullSafe`: не идёт самопроверка, банк, Quizlet, карточный режим, не печатаешь в поле). Realtime Supabase не включён (Влад решил пока без него).

## Два курса
- Переключатель FR / ES вверху сайдбара; выбранный курс — `localStorage["edito-course"]` и поле `course` в облачном документе `settings`. Атрибут `<html data-course="es">` включает тёплую тему.
- Испанский (Aula internacional Plus 1, юниты 1–4, вариант Испании — vosotros): `src/es-book.js` (хелперы + юнит 1), `es-book-2.js`, `es-book-3.js`, `es-book-4.js` (юнит 4 «¿Cuál prefieres?», у упражнений `w`, плюс `ES_POOL_U4(L)` — вопросы пробной, конкатенируются в `setData`), `es-gram.js` (спряжение -ar/-er/-ir, неправильные, произношение), `es-lexico.js` (лексика: [es, en, пример]), `es-lexico-4.js` (лексика юнита 4 и категории глаголов `u:"v"`), `es-test.js` (банк вопросов), `es-cheat.js` (шпаргалка `ES_CHEAT(LANG)`, раздел `#shpargalka` есть в обоих курсах).
- Испанский контент двуязычный: строки через `T(ru, en)`, собирается `ES_BUILD(LANG)` / `ES_POOL_BUILD(LANG)`. В объяснениях не сравнивать испанский с русским (исключение — возвратные глаголы); сравнения с английским — через `EsEN()`.
- id испанских тем начинаются с `es` — роутер по ним сам переключает курс. Прогресс и ответы хранятся по id темы, результаты пробных — с полем `c: "es" | "fr"`.
- Порядок и количество упражнений в теме менять только добавлением в конец (ответы хранятся по индексу).

- «Почему так» (v2, 25.10.2026): `src/why2.js` (реестр) + данные `why2-fr.js`, `why2-cahier.js`, `why2-es.js`, `why2-pool.js`. Для каждого задания `WHY2[topicId][exIndex] = {r:[ru,en] — общее правило, i:[[ru,en]…] — «почему здесь так» для каждого вопроса (mc/tf/fill), t:[ru,en] — разбор задания без отдельных вопросов (sort/match/order/cards/drill/listen/conj)}`. Вопросы пробной / банка — `WHYP_ADD("fr"|"es", {tp: {"текст вопроса (RU-версия, без HTML)": [ru, en]}})` в `why2-pool.js`. `why2-pool.js` должен идти последним из why2-файлов: в его конце `WHY2_APPLY` / `WHYP_APPLY` для французского; испанский применяется в `ES_BUILD` и `setData`.
- Проверка текстовых ответов — только по Enter.

## Французский: Livre / Cahier / Tutor
- **Сравнения с русским и английским** (просьба Влада 29.10.2026): во французском контенте (теория, «почему так», заметки) не сравнивать с русским/английским, кроме чётких параллелей (ты/вы, -ся, маленькая буква у дней и национальностей, «Я студент» без артикля, quel = какой, on = «говорят», a/an ↔ the, il y a = there is/are, si = «Yes, I do», circonflexe = s в hospital/forest, однокоренные слова). Противопоставления («в английском иначе», «калька с английского») не писать — правило формулировать про сам французский. В RU-версии — RU-параллель (EN только если она чёткая), в EN-версии — только EN.
- В сайдбаре французского вместо «Из учебника» — сегменты Livre / Cahier / Tutor (`FRMODE`, `localStorage["edito-frmode"]`). Роутер сам переключает режим по `sec` открытой темы.
- Livre — юниты 0–3. Юнит 3 (Qu’est-ce qu’on mange ?) лежит в `src/fr-u3.js`: двуязычная сборка `FR_U3(L)` через `TF(ru, en)`; там же вопросы пробной (push в POOL и POOL_EN) и наборы Quizlet (push в QSETS).
- «Test unité 1» — тема `u1-test` (kind `Test`, иконка-медаль) в `src/fr-test-u1.js`, вставляется после `u1-phonetique`; упр. 9 (аудирование) пропущено, WHY2 лежит в том же файле. «Test unité 2» — `u2-test` в `src/fr-test-u2.js` (после `u2-phonetique`), все 11 упражнений; упр. 9 (аудирование) — диалог восстановлен по расшифровке Влада, озвучивается в мини-плеере (`DLG["fr-u2-test"]`, у реплик есть переводы ru/en), текст спрятан в `<details>`. «Test unités 1–2» — `u12-test` в `src/fr-test-u12.js` (контрольная преподавателя по двум юнитам, вставляется после `u2-test`, самый конец юнита 2): грамматика и лексика, 11 заданий / 77 вопросов; часть I (аудирование) пропущена, предложения с двумя пропусками разбиты на два вопроса (второй пропуск — «…»). - Cahier — `src/fr-cahier.js`, темы `c0-…`–`c3-…` с `sec:"cahier"` (массив `CAH`), по страницам рабочей тетради, ответы по Corrigés. Аудио- и картиночные задания пропущены. Задания, которым нужен текст из теории, помечены `ctx:true` — их нет в банке.
- Tutor — `src/fr-tutor.js`: задания от репетитора, темы `t-…` с `sec:"tutor"` (массив `TUT` в движке), поле `unit` — к какому юниту учебника относится (группировка на главной, в сайдбаре и в банке). Добавляются в конец `TOPICS` / `TOPICS_EN`, «почему так» — `WHY2_ADD` в том же файле. Первое задание — `t-possessifs-1` (15 предложений на притяжательные). Если `TUT` пуст, показывается заглушка «скоро».

Главная `#quizlet`: «Занятие на сегодня» (юниты: все / 0–3, «Новых в день» 5–20 = `QZ.perDay`) → одна кнопка «Начать занятие»; ниже наборы по юнитам (Избранное — во вкладке «Мои сеты», см. v3). ## Общее для всех языков
- **Иконки — только Framework7 Icons** (MIT, Vladimir Kharlampidi; просьба Влада 26.10.2026).
