# «Учим языки шаг за шагом» (бывш. Révisions Édito A1) — заметки для правок

- Исходники в `src/`. После любой правки: `python3 src/build.py` — пересобирает `index.html` и копирует `supabase.js`, `schema.sql`, `README.md`, `.nojekyll` в корень.
- `config.js` в корне содержит URL и publishable key Supabase; сборка его не перезаписывает.
- GitHub Pages публикует ветку `main`, папку `/` (корень).
- Порядок и количество заданий в RU (`data-*.js`) и EN (`en-*.js`) должны совпадать: ответы хранятся по индексу. Новые упражнения — только в конец темы.
- Облако: таблица `user_docs` (см. `schema.sql`), ключи документов `progress`, `settings`, `quiz`, `ans-<topicId>`.
- Синхронизация: запись в облако через 0,7 с после изменения (`touch` → `flush`). Чтение — при загрузке (`initCloudRun`) и при возвращении на вкладку (`pullCloud`: visibilitychange / focus / online, не чаще раза в 4 с). Слияние в `mergeDocs(docs, pull)`; при pull документ `settings` (язык, курс) не применяется, а страница перерисовывается, только если это безопасно (`pullSafe`: не идёт самопроверка, банк, Quizlet, карточный режим, не печатаешь в поле). Realtime Supabase не включён (Влад решил пока без него).

## Два курса
- Переключатель FR / ES вверху сайдбара; выбранный курс — `localStorage["edito-course"]` и поле `course` в облачном документе `settings`. Атрибут `<html data-course="es">` включает тёплую тему.
- Испанский (Aula internacional Plus 1, юниты 1–4, вариант Испании — vosotros): `src/es-book.js` (хелперы + юнит 1), `es-book-2.js`, `es-book-3.js`, `es-book-4.js` (юнит 4 «¿Cuál prefieres?», у упражнений `w`, плюс `ES_POOL_U4(L)` — вопросы пробной, конкатенируются в `setData`), `es-gram.js` (спряжение -ar/-er/-ir, неправильные, произношение), `es-lexico.js` (лексика: [es, en, пример]), `es-lexico-4.js` (лексика юнита 4 и категории глаголов `u:"v"`), `es-test.js` (банк вопросов), `es-cheat.js` (шпаргалка `ES_CHEAT(LANG)`, раздел `#shpargalka` есть в обоих курсах).
- Испанский контент двуязычный: строки через `T(ru, en)`, собирается `ES_BUILD(LANG)` / `ES_POOL_BUILD(LANG)`. В объяснениях не сравнивать испанский с русским (исключение — возвратные глаголы); сравнения с английским — через `EsEN()`.
- id испанских тем начинаются с `es` — роутер по ним сам переключает курс. Прогресс и ответы хранятся по id темы, результаты пробных — с полем `c: "es" | "fr"`.
- Порядок и количество упражнений в теме менять только добавлением в конец (ответы хранятся по индексу).

## Платформа (вход, профиль, оформление)
- Модули `src/game.js` (виджет профиля в сайдбаре + журнал активности по дням), `src/platform.js` (экран входа/онбординг, аватар, оформление, личный кабинет), `src/study.js` (банк заданий `#bank`, карточный режим темы, «?» в пробной) встраиваются ВНУТРЬ IIFE движка: `build.py` подставляет их вместо маркера `/*@@MODULES@@*/` в `engine2.js`.
- Доступ только после входа (Supabase): `gateCheck()` → loading / auth / onboard. Без бэкенда — только онбординг локально.
- Облачные документы добавились: `profile` (имя, эмодзи, фон, выбранное оформление `eq`, тема light/dark/system) и `game` — сейчас из него используется только `hist` (сколько ответов в какой день) для календаря активности; старые поля xp/coins/streak/aw сохраняются, но не показываются.
- Геймификация (XP, уровни, монеты, стрик, магазин, промокоды) убрана по просьбе Влада 23.10.2026 — не возвращать без запроса. Всё оформление (палитры, рамки, узоры, курсоры, аватарки) доступно бесплатно во вкладке «Оформление».
- «Почему так» (v2, 25.10.2026): `src/why2.js` (реестр) + данные `why2-fr.js`, `why2-cahier.js`, `why2-es.js`, `why2-pool.js`. Для каждого задания `WHY2[topicId][exIndex] = {r:[ru,en] — общее правило, i:[[ru,en]…] — «почему здесь так» для каждого вопроса (mc/tf/fill), t:[ru,en] — разбор задания без отдельных вопросов (sort/match/order/cards/drill/listen/conj)}`. В «?» показывается: Ответ → «Почему здесь так» → «Правило». Старый `why.js` и поля `w` остаются запасным вариантом, WHY2 их перекрывает.
- При добавлении задания в конец темы добавь запись в WHY2 (r + i по числу вопросов или t). Вопросы пробной / банка — `WHYP_ADD("fr"|"es", {tp: {"текст вопроса (RU-версия, без HTML)": [ru, en]}})` в `why2-pool.js`. `why2-pool.js` должен идти последним из why2-файлов: в его конце `WHY2_APPLY` / `WHYP_APPLY` для французского; испанский применяется в `ES_BUILD` и `setData`.
- Проверка текстовых ответов — только по Enter.
- Карточный режим (`study.js`): теория режется по h2/h3, затем карточка «Теперь — практика» и по карточке на каждое задание. Блоки `.exb` физически переносятся из `.exs` в колоду (на их месте комментарий-плейсхолдер) и возвращаются при закрытии — состояние заданий одно и то же в обоих режимах.

## Французский: Livre / Cahier / Tutor
- В сайдбаре французского вместо «Из учебника» — сегменты Livre / Cahier / Tutor (`FRMODE`, `localStorage["edito-frmode"]`). Роутер сам переключает режим по `sec` открытой темы.
- Livre — юниты 0–3. Юнит 3 (Qu’est-ce qu’on mange ?) лежит в `src/fr-u3.js`: двуязычная сборка `FR_U3(L)` через `TF(ru, en)`; там же вопросы пробной (push в POOL и POOL_EN) и наборы Quizlet (push в QSETS).
- «Test unité 1» — тема `u1-test` (kind `Test`, иконка-медаль) в `src/fr-test-u1.js`, вставляется после `u1-phonetique`; упр. 9 (аудирование) пропущено, WHY2 лежит в том же файле. «Test unité 2» — `u2-test` в `src/fr-test-u2.js` (после `u2-phonetique`), все 11 упражнений; упр. 9 (аудирование) — диалог восстановлен по расшифровке Влада, озвучивается в мини-плеере (`DLG["fr-u2-test"]`, у реплик есть переводы ru/en), текст спрятан в `<details>`. «Test unités 1–2» — `u12-test` в `src/fr-test-u12.js` (контрольная преподавателя по двум юнитам, вставляется после `u2-test`, самый конец юнита 2): грамматика и лексика, 11 заданий / 77 вопросов; часть I (аудирование) пропущена, предложения с двумя пропусками разбиты на два вопроса (второй пропуск — «…»). Тесты других юнитов добавлять так же: отдельный файл + тема в конец юнита.
- Cahier — `src/fr-cahier.js`, темы `c0-…`–`c3-…` с `sec:"cahier"` (массив `CAH`), по страницам рабочей тетради, ответы по Corrigés. Аудио- и картиночные задания пропущены. Задания, которым нужен текст из теории, помечены `ctx:true` — их нет в банке.
- Tutor — `src/fr-tutor.js`: задания от репетитора, темы `t-…` с `sec:"tutor"` (массив `TUT` в движке), поле `unit` — к какому юниту учебника относится (группировка на главной, в сайдбаре и в банке). Добавляются в конец `TOPICS` / `TOPICS_EN`, «почему так» — `WHY2_ADD` в том же файле. Первое задание — `t-possessifs-1` (15 предложений на притяжательные). Если `TUT` пуст, показывается заглушка «скоро».
- `src/fr-plus.js` и `src/es-plus.js` — блоки «Частые ошибки» (класс `.mist`) и новые задания в конец существующих тем; WHY для них добавляется автоматически из поля `w:[ru, en]`.
- В новых файлах у каждого упражнения поле `w:[ru, en]` — это «почему так»; WHY заполняется из него.
- Тип `order` поддерживает `sep:"|"` для упорядочивания фраз, а не слов.

## Общее для всех языков
- **Иконки — только Framework7 Icons** (MIT, Vladimir Kharlampidi; просьба Влада 26.10.2026). В коде: `f7("name", "класс")`, пара «выкл/вкл» — `f7on("heart", "heart_fill")` (видна `f7-on`, когда у родителя `.on` или `aria-pressed="true"`), стрелки в кнопках — `ARR` / `ARL` / `ARD`; в `shell.html` — `{{f7:name}}` и для CSS-масок `{{f7url:name}}`. Пути иконок лежат в `src/f7-icons.json`; после добавления новой иконки: `npm pack framework7-icons`, распаковать и `python3 src/f7gen.py <папка>/package/svg` (он берёт только используемые). `build.py` встраивает `F7`/`f7` в начало скрипта и падает, если иконки нет в json. Значки ✓ ✗ ★ ✦ в контенте заменяет на иконки `glyphIcons()` (MutationObserver). Не добавлять свои SVG-иконки, эмодзи-значки и символы-иконки (♥ ▶ ✎ ↶ 📅); эмодзи остаются только как аватарки, узоры фона и курсоры — это оформление, а не иконки.
- Все сегментированные переключатели (`.seg`, `.seg.big`, `.lang-sw`, `.qz-modes`, `.frmode`) — один стиль, как на главной: подложка `--fill`, радиус 11, padding 4, кнопки радиус 8, активная — белая с тонкой обводкой. Общее правило — в конце слоя v4 в `shell.html`; новые переключатели делать классом `seg`.
- `src/tools.js` (модуль внутри движка, как game/platform/study): **переводчик** — открывается и иконкой `.tr-fab` (просто приглушённый глобус без подложки, правый нижний угол; скрыта на экране входа и пока панель открыта; если что-то выделено — подставляет выделение), а также выделение длиннее 80 символов или 8 слов показывает в окошке `.selpop.long` кнопку «Перевести» → панель `.trp` (справа; на телефоне ≤760px шторка снизу): языки курс/ru/en, смена направления, озвучка `sayIn`, копирование, до 1500 символов, перевод MyMemory кусками ≤450 символов (`trChunks`). **Мини-плеер диалогов** `.ply` (снизу по центру панели, на телефоне сверху и сдвигает кнопку «Темы» через `--ply-h`): диалоги регистрируются в `DLG[id] = {lang, title, lines:[[кто, текст]…]}` (`DLG` объявлен в `visuals.js`), кнопка — любой элемент с `data-dlg="id"`. Синтез речи по репликам, позиция по событиям boundary или по оценке времени (`CPS`), ±5 с, скорость — выпадающее меню 0,5–2× (`plyMenu`), кнопка слов циклически: выкл → слова в реальном времени → слова + перевод реплики (`PLY.show` 0/1/2, `edito-ply-words`; перевод берётся из `lines[i][2]` ru / `[3]` en, иначе автоперевод `plyTr`), крестик. Пока плеер играет, `pullSafe` не перерисовывает страницу.
- `speak()`: повтор той же фразы в течение 15 с замедляет её (0.62, затем 0.5).
- Китайский — пока только заглушка: пункт в выпадающем списке курсов ведёт на `#zh` (`VIEW_ZH`, `renderZh()`), это не настоящий COURSE — данные и прогресс не трогаются.
- Испанское избранное: сердечко в плашке перевода → `S.quiz.esfav` = [{es, m, at}] (облачный документ `quiz`), показывается в Лексике по чипу «Избранное» (`#lexFavSec`). Французское избранное по-прежнему `S.quiz.fav` (Quizlet).
- Тема «+ / − / ?» (как строить утверждение, отрицание, вопрос) есть в справочнике обоих курсов: французская `r-phrase` в `src/fr-phrase.js` (вставляется перед `r-questions`), испанская `esr-frase` в `src/es-frase.js`. Схема из трёх карточек — хелпер `S3(...)`, заголовки столбцов — `S3TH(...)` (оба в `visuals.js`). Карточка «+ · − · ?» — первая в шпаргалках.
